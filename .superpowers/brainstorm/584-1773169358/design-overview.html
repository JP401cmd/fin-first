2. Scoring Systeem

lib/ai-dashboard-builder.ts
Input
  • focus: string[] (max 2)
  • module: 'kern' | 'wil' | 'horizon' | 'balanced'
  • detail: 'compact' | 'balanced' | 'detailed'
  • favBudgets: string[]
  • sovereigntyLevel: number
Output
  • WidgetPref[] die exact 16 cellen vult
  • Elke pref: { id, enabled, size, order }
Score-berekening per widget:
score = focusBonus(widget, focus) × 3
     + moduleBonus(widget, module) × 2
     + popularityBase(widget)
     - levelPenalty(widget, sovLevel)
Formaat-toewijzing op basis van detail:
Detail Full (4c) Half (2c) Quarter (1c)
Compact 0 4 8
Gebalanceerd 1 4 4
Uitgebreid 2 2 4
Totaal altijd = 16 cellen. Budget-favorieten nemen quarter-slots in.
