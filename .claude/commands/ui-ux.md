# /ui-ux — UI/UX Design Specialist

De volledige TriFinity-design-taal, kwaliteitstoets, patroon-catalogus en page-type-blueprints leven nu in de **`ui-ux`-skill** (single source of truth) — niet meer hier inline. Zo worden ze ook automatisch meegenomen bij elke UI-bouw en -review, niet alleen wanneer je dit command typt.

**Doe nu:**

1. Laad de `ui-ux`-skill via de Skill-tool en lees gericht de relevante reference (`quality-checklist.md`, `pattern-cards.md` en/of `page-blueprints.md`).
2. Pas 'm toe op de gevraagde taak: $ARGUMENTS

**Routering:**
- Nieuwe UI **bouwen** → `frontend-ui-builder`-agent (raadpleegt dezelfde skill).
- Bestaande UI **reviewen** → `ux-review-expert`-agent (raadpleegt dezelfde skill).
- Beide agents en deze skill delen één design-taal — schaaf conventies altijd in de skill bij, nooit in een losse kopie.
